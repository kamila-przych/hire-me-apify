Onboarding and offboarding

Pre-onboarding, onboarding and offboarding in one system

Onboarding workflow

  • Pre-onboarding platform: new hires see what is waiting for them and their tasks before day one
  • Tasks for each owner: new hire, People Team, manager, IT
  • Automatic enrolment in lifecycle feedback surveys
  • Documents sent for signature automatically

Offboarding workflow

  • Tasks for each owner: leaver, People Team, manager, IT
  • Set up by exit type and legal entity
  • Automatic enrolment in the exit feedback survey
  • Documents sent for signature automatically

Why: everyone involved works in one system, Leapsome, with no other tool needed. I launched it in my first 3 months, and 20 people have been onboarded with it so far.
